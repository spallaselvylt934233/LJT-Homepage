# LJT-Homepage

Personal academic homepage of Junteng Liu, built with the [Academic Pages template](https://github.com/academicpages/academicpages.github.io) and hosted on GitHub Pages.

* First-year PhD candidate at the HKUST NLP Group, Hong Kong University of Science and Technology.
* Research focuses on natural language processing and machine learning.
* Contact: jliugi@connect.ust.hk

The site contains an About page with academic background, research experience, publications, skills and contact information, a Publications page, and a CV page. The publications are stored as Markdown files in `_publications/`, and the site configuration is in `_config.yml`.
